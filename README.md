# Projet GBC – Émulateur Game Boy Color

Projet personnel : écrire un émulateur Game Boy, puis Game Boy Color,
pour comprendre comment fonctionnent un processeur, la mémoire et l'affichage.

## État du projet
🚧 Démarrage. Rien n'est encore fonctionnel.

## Objectifs
1. Désassembleur de ROM
2. CPU validé avec les ROM de test de Blargg
3. Affichage et entrées : lancer Tetris/Pokemon Cristal
4. Mappers (MBC) et sauvegardes
5. Mode Game Boy Color

## Ressources
- [gbdev.io](https://gbdev.io)
- [Pan Docs](https://gbdev.io/pandocs/)

## Usage de l'IA
J'utilise l'IA pour comprendre des notions et relire mon code,
pas pour générer l'émulateur.
